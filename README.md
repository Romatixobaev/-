Литература
----------
Список рекомендуемой к прочтению литературы:

2. Бернд Яне. Цифровая обработка изображений. Москва: Техносфера, 2007. – 584 с.
3. Ричард Дуда, Питер Харт. Распознавание образов и анализ сцен. Москва: Мир, 1976. – 512 с.
